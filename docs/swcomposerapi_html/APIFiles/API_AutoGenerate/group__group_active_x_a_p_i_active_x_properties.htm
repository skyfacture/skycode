Composer Player API - Player Plug-in Properties

The tables below have the following color coding:

  
Orange shading indicates advanced Player Plug-in features. An application using advanced features must be run from a computer with a Composer Player Pro license installed. An error message appears when an advanced function is run without a Composer Player Pro license.

Green shading indicates Composer Player plug-in properties that you can specify as application parameters. For example, to enable ground grid but disable auto play, specify:
<param name="GroundGrid" value="1">
<param name="AutoPlay" value="0">
Specifying properties that are stored in the Composer document has no effect.

The following table describes all control properties.

Note: Each property has a "set" and a "get" mode. Use arguments for "set" mode but not "get" mode.


 Description Arguments
AllNameOccurences as Boolean Manages the ability to select all the occurences of the object.

1: True. All the occurences of the object will be selected
0: False. Only the object that matches the Net Guid (if UseGUID is True) or the name will be selected
AntiAliasingOnIdle as Boolean Applies anti-aliasing when no action is performed.

1: True
0: False
ApplicationProfile as Integer
Specifies the application-settings profile used by all Composer applications.

CrApplicationProfile enum value:

  • crApplicationProfileStandard (0): Standard
  • crApplicationProfileHighSpeed (2): High speed
  • crApplicationProfileHighQuality (3): High quality
  • crApplicationProfileSafe (4): Safe
AssySelectionMode as Boolean Enables assembly selection mode.

1: True
0: False
AssySelectionModeViewportIndicator as Boolean
 Displays a blue border around the viewport to indicate assembly selection mode.
 1: True
0: False
AutoKeyMode as Boolean Enables auto-key mode. 1: True
0: False
AutoPlay as Boolean Automatically plays the animation when Composer Player opens the Composer file. 1: True
0: False
BorderMask as Boolean Applies a border on the plug-in window. 1: True
0: False
CameraInertia as Boolean Enables camera inertia mode.
 1: True
0: False
CameraPlayMode as Boolean Shows camera movement during animation. 1: True
0: False
CameraSmoothTime as Integer Applies smooth transitions between view changes.

0: No transitions
100: Smooth transitions
EventsMask as Long Filters some fired events which can be time consuming on big models (OnChangeVisibility, OnChangeSelection, and OnChangeProperties).

Note: By default, these events are not sent anymore.		 OnChangeVisibility: 1 (bit 0)
OnChangeSelection: 2 (bit 1)
OnChangeProperties: 4 (bit 2)

Example: To catch OnChangeVisibility and OnChangeProperties: events mask = 1 + 4 = 5

The default value is 2.
FileName as String Opens a Composer file. The path to the file can be relative or absolute. Filename, for example: "scenes/animation.smg"
GroundGrid as Boolean Turns on the ground actor.

Note: By default, this property overrides the corresponding document property when a document is opened. Use OverloadedDocProperties to disable overloading.
 1: True
0: False
HighlightedObject as String Allows highlighting actors or seeing which one is currently highlighted.

Note: "set" mode requires a Composer Player Pro license.
Selection, for example:

By name:
 
<CLitSelection Name=""> 
  <CLitModifiable Name="Body01"/>
</CLitSelection>
By ID:
 
<CLitSelection Name="">
  8cb9b30b4874ac23#
</CLitSelection>
LoopPlay as Boolean
 Enables Loop Play mode, which plays the animation continuously.
 1: True
0: False
NoHighlight as Boolean Disables actor highlighting. 1: True
0: False
OverloadedDocProperties as Long Specifies which Player plug-in properties (specified as a CrOverloadedDocumentProperties mask) override the corresponding document properties. By default, all these document properties are overloaded by Player plug-in properties.

CrOverloadedDocumentProperties enum values:

  • crOdpNone (0): Disables overloading for all these properties
  • crOdpRenderGroundShadow (1)
  • crOdpRenderMode (2)
  • crOdpGroundGrid (4)
  • crOdpAll (7): Enables overloading for all these properties (the default)
Example: To disable the RenderGroundShadow property from overriding document settings, specify 6 (2 + 4).
PMICrossHLOpacity as Single Specifies the opacity of the surface attached to product manufacturing information (PMI). 0: Transparent
255: Translucent
PMICrossHLStayOnTop as Boolean Makes hidden surfaces visible when selecting or highlighting related PMI. 1: True
0: False
Pos as Long Changes the position of the animation cursor in the timeline. The "get" mode returns the current frame; the "set" mode put the cursor on the specified frame. Targeted frame
PromptToUpdateView as Boolean Enables the display of the dialog box when switching from one view to another, or when leaving the view mode.
1: True
0: False
RemoveMeasurementCommands as Boolean Removes all measurement commands, including the measurement toolbar. To make measurement commands available but hide the measurement toolbar, set this property to 0 and set ShowMeasurementToolBar to 0.
1: True
0: False
RenderGroundShadow as Boolean Displays model shadows on the ground actor.

Note: By default, this property overrides the corresponding document property when a document is opened. Use OverloadedDocProperties to disable overloading.
 1: True
0: False
RenderMode as Integer Changes the render mode of the 3D scene.

Note: By default, this property overrides the corresponding document property when a document is opened. Use OverloadedDocProperties to disable overloading.

CrRender enum value:

  • crRrmSmooth (0): Smooth
  • crRrmSmoothWithOutlines (1): Smooth with Outline crRrmTechnical (2): Technical
  • crRrmTechnicalFlat (3): Flat Technical
  • crRrmSilhouette (4): Silhouette
  • crRrmFlat (5): Flat
  • crRrmWireframe (6): Wireframe
  • crRrmPoint (7): Points
  • crRrmShadedIllustration (8): Shaded Illustration
  • crRrmShadedIllustrationWithColors (9): Shaded Illustration with Color
  • crRrmShadedIllustrationSimple (10): Shaded Illustration Without Silhouette
  • crRrmCustomRendering (11): Custom

Additionally its allows you to select from Selection Sets.
