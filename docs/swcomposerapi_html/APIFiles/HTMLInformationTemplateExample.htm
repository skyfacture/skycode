Example: Using the Information HTML Template

The Composer API and Composer Player ActiveX API let you control the display of meta-properties using a dedicated HTML template.

Code fragments are in red.

HTML Code of the Template

<html>
<head>
    <meta http-equiv="content-type" content="text/html; charset=utf-8" />
    <title></title>
    <style>
        body
        {
            background-color: #F3F3F3;
        }
        .meta_container
        {
            display: block;
            position: relative;
            overflow: hidden;
            width: 100%;
            padding: 3px;
            border-bottom: 1px solid #DADADA;
            font-family: Verdana, Geneva, Tahoma, sans-serif;
            font-size: 11px;
        }
        .meta_name
        {
            font-weight: bold;
            width: 40%;
            max-width: 200px;
            height: auto;
            float: left;
            display: inline-block;
            word-wrap: break-word;
        }
        .meta_value
        {
            width: 60%;
            min-height: 15px;
            height: auto;
            float: left;
            display: inline-block;
            word-wrap: break-word;
        }
    </style>
</head>
<body>
    <div id="ALL_METAS_TEMPLATE" class="meta_container">
        <div>
            <div class="meta_name">
                $(ALL_METAS).Name</div>
            <div class="meta_value">
                $(ALL_METAS)</div>
        </div>
    </div>
</body>

Use Cases

  1. To display a meta-property:

    <div class="meta_container">
        <div class="meta_name">$(Meta_Property_Name).Name</div>
        <div class="meta_value “>$( Meta_Property_Name)</div>
    </div>

    Example, with C_modified being a meta-property:

    <div class="meta_container">
        <div class="meta_name">$(C_modified).Name</div>
        <div class="meta_value">$(C_modified)</div>
    </div>

  2. To display the selected actor's parent's meta-property, with ParentLevel being a digit (1= actor's parent, 2=actor's grand-parent, and so on):

    Property Name: $(ParentLevel#Meta_Property_Name).Name
    Property Value: $(ParentLevel#Meta_Property_Name)

    Example, with C_modified being a meta-property:

    <div class="meta_container">
        <div class=meta_name>$(1#C_modified).Name</div>
        <div class=meta_value>$(1#C_modified)</div>
    </div>

  3. To display meta-properties using the NetGUID of the actor:

    Property Name: $(NetGUID#Meta_Property_Name).Name
    Property Value: $( NetGUID#Meta_Property_Name)

    Example, with C_modified being a meta-property displayed by its netGUID:

    <div class="meta_container">
        <div class=meta_name>$(a7ebc89bd236726b.a0488ba792ea999e.ARotor #C_modified).Name</div>
        <div class=meta_value>$(a7ebc89bd236726b.a0488ba792ea999e.ARotor #C_modified)</div>
    </div>

  4. To display all meta-properties of the actor:

    <div id = "ALL_METAS_TEMPLATE" class="meta_container">
        <div>
            <div class="meta_name">$(ALL_METAS).Name</div>
            <div class="meta_value">$(ALL_METAS)</div>
        </div>
    </div>
  5. To graphically display colors and their values:

    <div attr="META_COLOR_TEMPLATE">
      <div style="background-color:META_COLOR_VALUE;height:15px;width:15px;border-radius:8px;"></div>
      META_COLOR_VALUE
    </div>  

    Note: if used, this sub-template will be automatically appended to the tags containing meta-properties of the color type in the HTML template.
    For example, if there is a meta-property call Part_Color with its value as red color, and if you add the color meta-property as follows:
    <div class="meta_container">
        <div class="meta_name">$(Part_Color).Name</div>
        <div class="meta_value">$(Part_Color)</div>
    </div>
     In this case, the sub-template for color will be appended with the above tag, with the replaced property name and color value, as follows:
    <div class="meta_container">
        <div class="meta_name">Part_Color</div>
        <div class="meta_value">
            <div attr=""META_COLOR_TEMPLATE">
                 <div style="background-color:#FF0000;height:15px;width:15px;border-radius:8px;"></div>
                 #FF0000
                   </div>
        </div>
    </div>

  6. To display a boolean value (yes/no check box):

    <div attr="META_BOOL_TEMPLATE">
      <input type="checkbox" disabled META_BOOL_VALUE> 
    </div>

    Note: if used, this sub-template will be automatically appended to the tags containing meta-properties of the boolean type in the HTML template.
    For example, if you add the boolean meta-property tag as follows:
    <div class="meta_container">
        <div class="meta_name">$(Part_Availibility).Name</div>
        <div class="meta_value">$(Part_Availibility)</div>
    </div>
     In this case, the sub-template for boolean will be appended with the above tag, with the replaced property name and boolean value, as follows:
    <div class="meta_container">
        <div class="meta_name">Part_Availibility</div>
        <div class="meta_value"><input type="checkbox" disabled checked></div>
    </div>
