Composer API - Document Properties


Note: Each property has a "set" and a "get" mode. Use arguments for "set" mode but not "get" mode.

Property
 Description Arguments and Examples
AllNameOccurences as Boolean Manages the ability to select all the occurences of the object.

1: True. All the occurences of the object will be selected
0: False. Only the object that matches the Net Guid (if UseGUID is True) or the name will be selected
AssySelectionMode as Boolean Enables assembly selection mode.

1: True
0: False
AutoKeyMode as Boolean Enables auto-key mode. 1: True
0: False
CameraInertia as Boolean Enables camera inertia mode. 1: True
0: False
CameraPlayMode as Boolean Shows camera movement during animation. 1: True
0: False
CameraSmoothTime as Integer Applies smooth transitions between view changes.

0: No transitions
100: Smooth transitions
DropInViewport as Boolean Manages the ability to drag and drop files in the viewport, for merging in the current document.

1: True. Enables drag and drop
0: False. Disables drag and drop
EventsMask as Long Filters the specified events. These events (OnChangeVisibility, OnChangeSelection, and OnChangeProperties) can be time consuming on large models

Note: By default, these events are not sent anymore.		 OnChangeVisibility: 1 (bit 0)
OnChangeSelection: 2 (bit 1)
OnChangeProperties: 4 (bit 2)

Example: To catch OnChangeVisibility and OnChangeProperties: events mask = 1 + 4 = 5

The default value is 2.
FileName as String Returns which file is opened. The main method to open a new file is Open(). Filename, for example: "scenes/animation.smg"
GroundGrid as Boolean Shows the ground actor. 1: True
0: False
HighlightedObject as String Enables highlighting actors or seeing which one is currently highlighted.

Note: "set" mode requires a Composer Player Pro license. 		Selection, for example:

By name:
 
<CLitSelection Name=""> 
  <CLitModifiable Name="Body01"/>
</CLitSelection>
By ID:
 
<CLitSelection Name="">
  8cb9b30b4874ac23#
</CLitSelection>
NoHighlight as Boolean Disables actor highlighting. 1: True
0: False
Pos as Long Changes the position of the animation cursor in the timeline. The "get" mode returns the current frame; the "set" mode put the cursor at the specified frame. Targeted frame
PMICrossHLOpacity as Single Specifies the opacity of the surface attached to product manufacturing information (PMI). 0: Transparent
255: Translucent
PMICrossHLStayOnTop as Boolean Makes hidden surfaces visible when selecting or highlighting related PMI. 1: True
0: False
RenderGroundShadow as Boolean Displays model shadows on the ground actor. 1: True
0: False
RenderMirror as Boolean Displays the model mirror image on the ground actor. 1: True
0: False
RenderMode as CrRender Changes the render mode of the 3D scene.

CrRender enum value:

  • crRrmSmooth (0): Smooth
  • crRrmSmoothWithOutlines (1): Smooth with Outline
  • crRrmTechnical (2): Technical
  • crRrmTechnicalFlat (3): Flat Technical
  • crRrmSilhouette (4): Silhouette
  • crRrmFlat (5): Flat
  • crRrmWireframe (6): Wireframe
  • crRrmPoint (7): Points
  • crRrmShadedIllustration (8): Shaded Illustration
  • crRrmShadedIllustrationWithColors (9): Shaded Illustration with Color
  • crRrmShadedIllustrationSimple (10): Shaded Illustration Without Silhouette
  • crRrmCustomRendering (11): Custom
Selection as String Lets you select an actor or see which one is currently selected.
Additionally its allows you to select from Selection Sets.
Note: "set" mode requires a Composer Player Pro license.
 Selection, for example:

By name:
 
<CLitSelection Name=""> 
  <CLitModifiable Name="Body01"/>
</CLitSelection>
By ID:
 
<CLitSelection Name="">
  8cb9b30b4874ac23#
</CLitSelection>
Selection Sets, for example:

By name:
<CLitList>
  <CLitSelection Name="Selection 1"/>
  <CLitSelection Name="Selection 2"/>
</CLitList>
By ID:
 
<CLitList>
  <CLitSelection Ident="b6cf29c6bac8ea4a"/>
  <CLitSelection Ident="8cb9b30b4874ac23"/>
</CLitList>
StartupView as String

Opens a file on a specific view.

Name of the view.
UseGUID as Boolean Specifies whether to return actor names or GUIDs in selections. 1: True, use GUIDs
0: False, use names
ViewNameTemplate as String Defines the template to use for view names when creating views.
You can use alphanumeric characters, as well as the following optional variables, in any order:
- %filename%: inserts the name of the file containing the model, without its extension.
- %viewnumber%: inserts the number of the view, such as 1 for the first-created view.		 Value of the template, for example: "%filename%_View_%viewnumber%", or "Demo of %filename%, View %viewnumber%"
