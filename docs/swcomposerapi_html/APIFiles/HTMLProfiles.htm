HTML Profiles

HTML profiles determine the features included in HTML output when you publish to HTML from Composer (File > Publish > HTML). Composer provides several predefined profiles in <install_dir>\Profiles. Each profile has two files:

  • *.smgPublishHtmlSet is an XML file that defines the HTML features.
  • *.jpg is the preview image that is displayed in the Save As dialog box when a user publishes to HTML.

You can customize your HTML output by creating your own profiles and putting them in an HTML Publish data-path folder (see Application Preferences - Data Paths in Composer Help). Unlike workshop profiles, Composer does not provide a graphical interface for creating HTML profiles. Use a text editor.

To create a .smgPublishHtmlSet file, start with a predefined profile and then change the following tags as needed:

Tag
 Type
 Description
TopBar
 Boolean
 Not implemented. Always set to 0.
BottomBar
 Boolean
 Displays (1) or hides (0) the bottom bar, which is where the following feature panes are displayed: BOM, Meta, PMI, View. Only hide the bottom bar when all these features are disabled (such as the Simple profile).

Note: The bottom bar can display at most 3 panes.
TopNavigationBar
 Boolean
 Displays (1) or hides (0) the navigation toolbar at the top of the HTML page.
Meta.Name
 String
 Specifies the profile name as it appears to users in the Save As dialog box.

Note: Meta.Name and Meta.Description support localized strings.
Meta.Description
 String
 Specifies the detailed description of the profile.

Note: The description is not currently displayed to users in Composer.
PreviewImage
 String
 Specifies the image (.jpg) file containing the profile thumbnail image.
BOM
 Boolean Displays (1) or hides (0) the BOM Table pane.
Meta
 Boolean Displays (1) or hides (0) the Meta-properties pane.
PMI
 Boolean Displays (1) or hides (0) the PMI (product manufacturing information) pane.
DetailView
 Boolean Displays (1) or hides (0) the Detail View pane.
View
 Boolean Displays (1) or hides (0) the Views pane.
Tree
 Boolean Displays (1) or hides (0) the Assembly pane.

Note: The Assembly pane can take a long time to load for models with large numbers of nodes in the assembly tree. Consider hiding the HTML Assembly pane and use the Composer Player Assembly tree instead.

Note:
  • The bottom bar can display at most three of the following features at the same time: BOM, Meta, PMI, and View.
  • Most features require Composer Player Pro. When a published HTML file is opened without a Player Pro license, the Simple profile is always used.
For example, the following is the Full (Full.smgPublishHtmlSet) profile definition:
<CLitPublishHtmlProperties>
  <Profile.Modifiable Value="1"/>
  <Profile.AssociatedFile Value=""/>
  <TopBar Value="0"/>
  <BottomBar Value="1"/>
  <TopNavigationBar Value="1"/>
  <Server Type="PropertyDefinitions">
    <MetaProperties>
      <Meta Name="Meta.Name" Type="String" DefaultLabel="Full">
        <Localizations>
          <Localization Lang="FRA">
            <Label Value="Full"/>
          </Localization>
          <Localization Lang="DEU">
            <Label Value="Full"/>
          </Localization>
          <Localization Lang="JPN">
            <Label Value="Full"/>
          </Localization>
          <Localization Lang="CHS">
            <Label Value="Full"/>
          </Localization>
          <Localization Lang="KOR">
            <Label Value="Full"/>
          </Localization>
        </Localizations>
      </Meta>
      <Meta Name="Meta.Description" Type="String" DefaultLabel="">
        <Localizations>
          <Localization Lang="FRA">
            <Label Value=""/>
          </Localization>
          <Localization Lang="DEU">
            <Label Value=""/>
          </Localization>
          <Localization Lang="JPN">
            <Label Value=""/>
          </Localization>
          <Localization Lang="CHS">
            <Label Value=""/>
          </Localization>
          <Localization Lang="KOR">
            <Label Value=""/>
          </Localization>
        </Localizations>
      </Meta>
    </MetaProperties>
  </Server>
  <Meta.Name Value=""/>
  <Meta.Description Value=""/>
  <PreviewImage Value="Full.smgPublishHtmlSet.jpg"/>
  <BOM Value="1"/>
  <Meta Value="1"/>
  <PMI Value="0"/>
  <DetailView Value="1"/>
  <View Value="1"/>
  <Tree Value="1"/>
</CLitPublishHtmlProperties>
