Example: Using Composer Player in PowerPoint

You can create Microsoft PowerPoint presentations with linked or embedded Composer files. You must have Composer Player installed on the same computer as PowerPoint. The procedure for using Composer Player in Microsoft Word documents is similar.

To insert a Composer (.smg) file in PowerPoint:

  1. Open a document in PowerPoint.
  2. Do one of the following:
    • In PowerPoint 2003, click View > Toolbars > Control Toolbox, and then click More Controls on the Control Toolbox toolbar.
    • In PowerPoint 2007, click More Controls on the Developer tab.

      Note: If the Developer tab is not in your Ribbon, select Show Developer tab in the Ribbon on the Popular page of the PowerPoint Options dialog box.

  3. In the More Controls dialog box, click Composer Player ActiveX and click OK.

    Note: If Composer Player ActiveX is not listed, register the Composer Player ActiveX control manually.

  4. In your document, drag a large rectangle to insert the control. This is where Composer Player displays the file.
  5. Right-click the control and click Composer Player ActiveX Object > Properties.
  6. In the Composer Player ActiveX Properties dialog box:
    1. On the General tab, select the Composer file and select render options.

      Note: Select Pack Composer document to embed the Composer document in the PowerPoint file. When this option is cleared, the PowerPoint file references the Composer file on disk. Referencing the file has the benefits that changes to the Composer file are reflected automatically in the PowerPoint file and the PowerPoint file is smaller. However, you must be certain that the Composer file remains available and in the correct location.

    2. On the Layout tab, select the toolbars and panes to display.
    3. Click OK.
  7. To preview your Composer document, right-click the control and click Composer Player ActiveX Object > Edit.
