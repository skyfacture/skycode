Controlling U3D Models with Acrobat JavaScript

Note: This topic requires knowledge of the Adobe JavaScript implementation. It is recommended that you read the Acrobat JavaScript and Acrobat 3D JavaScript reference documentation.

Composer uses the Adobe 3D JavaScript engine to control camera animations, views, and interactive BOMs of Universal 3D (U3D) content. If you need additional control over the 3D model, use Acrobat to add your own JavaScript code. To access the functions attached to the U3D scene from within the PDF document, use the getAnnot3D method, from which you can access annotation 3D context:
c3D = getAnnot3D( 0 , "Seemage3DAnnot0" ).context3D;

You can now use Acrobat 3D JavaScript to control the model. For example, the following code prints the number of meshes in the scene to the console:
console.println( c3D.scene.meshes.count );

Depending on the U3D publication options you selected, Composer adds certain methods to the c3D object:
  • setConfig(n) - Sets the 0-based nth configuration.
  • layerManager.hideLayer("layer name") - Hides the specified layer.
  • layerManager.showAllLayers() - Shows all layers.
  • layerManager.hideAllLayers() - Hides all layers.
  • setLayerToOriginalRenderMode("layer name") - Shows the layer in question.
Note: A layer is a group in the BOM.
