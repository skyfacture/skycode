Registering the Composer Player ActiveX Control

To embed Composer Player in other document types (such as Microsoft Word or HTML), the Composer Player ActiveX control file (<install_dir>\bin\ComposerPlayerActiveX.ocx) must be registered on your computer. This file is registered automatically when you install Composer.

If necessary, you can also register the ActiveX control manually by running one of the following files:

<install_dir>\bin\Register.bat
 Registers the 32- or 64-bit version of the Composer Player ActiveX (ComposerPlayerActiveX.ocx) depending on which Composer version is installed.
<install_dir>\bin\RegisterAll.bat
 Registers the 32- and 64-bit versions of the Composer Player ActiveX, and the Composer SOLIDWORKS add-in (ComposerSolidWorksPlug-in.dll).

For example, run RegisterAll.bat when you have Composer x64 installed but need to register the 32-bit version of the Composer Player ActiveX control for use in a 32-bit application.
