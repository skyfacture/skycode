Composer Players Plug-in Examples

The Composer Players Plug-in lets you insert Composer (.smg) files into third-party applications such as Microsoft PowerPoint and Microsoft Word, and to view Composer files with Internet Explorer.

  • Insert in applications

    You can embed the Composer Player in many software applications to create elaborate content. For an example, see Example: Using Composer Player in PowerPoint.

  • Insert in HTML pages

    You can use the Composer command Publish to HTML to create HTML pages with Composer content. Or, you can use an HTML editor. For an example, see Example: Using Composer Player in HTML. Once you have a Composer Player control in an HTML page, you can change its default parameters.
