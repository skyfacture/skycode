Application Programming Interfaces

Composer includes three application programming interfaces (APIs):

  • Composer API - Lets you manage Composer programmatically so you can integrate Composer with external systems.
  • Composer Player ActiveX API - Lets you insert Composer documents into third-party applications such as Microsoft PowerPoint and Microsoft Word, and to view Composer documents with Internet Explorer.
Using these APIs requires only a standard Composer license.

Note: For enumerated types, specify string constants when supported by your language to avoid dependence on internal integer values. For example, to set Technical render mode, specify RenderMode(crRrmTechnical) instead of RenderMode(2). Some languages, including JavaScript, require that you specify integer values.
