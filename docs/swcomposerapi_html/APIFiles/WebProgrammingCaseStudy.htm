Example: Using Composer Player in HTML

You can embed the Composer Players Plug-in in HTML pages to create interactive Web content. You can publish to HTML from Composer (File > Publish > HTML), which uses the default template in <install_dir>\Html, or you can create your own templates. You can also use HTML profiles to configure the HTML output.

The following programming example shows how to display highlighted actor names, change actor materials, and create links from an HTML document using JavaScript.

Code fragments are in red.

  1. Prerequisite setting functions needed to support Internet explorer and Firefox. 

    <script type="text/javascript">
      function isIE() {
        return (false || !!document.documentMode);
      }

      function getObject() {
        if (isIE())
          myObject = document.getElementById('_ComposerPlayerActiveX');
        else
          myObject = document.getElementById('_ComposerPlayerPlugin');

        return myObject;
      }

      function addEvent(obj, name, func) {
        if (obj.attachEvent)
          obj.attachEvent(name, func);
        else
          obj.addEventListener(name, func, false);
      }

      function ComposerWebPlayerLoaded() {
        registerEvents();
        myObject.FileName = "[FileName]";
      }
    </script>

    where:

    • isIE() function is used to find whether the browser is Internet Explorer or not.
    • getObject() function gives us the PlugIn object based on the browser. For Internet Explorer we get plugin object as Composer Player ActiveX control and for Firefox we get object of Composer Player Plugin.
    • addEvent(...) function registers events for Composer PlugIn. It handles event registration for both Internet Explorer and Firefox.
    • ComposerWebPlayerLoaded() function is specific to Firefox plugin, it is triggered by the onload event of the plugin. In this, registerEvents() function is used for registering different events (like GetHighlight, ChangeSelection etc.) by calling the addEvent(...) while myObject.Filename is used to specify the file to open.

  2. Embed Composer Player in an HTML page by inserting the following code between the <body> and </body> tags: 
    <!--[if IE]>
      <object id="_ComposerPlayerActiveX" height="100%" width="100%" classid="CLSID:410B702D-FCFC-46B7-A954-E876C84AE4C0" codebase="ComposerPlayerActiveX.cab#version=7,1,0,2762">
      <param name="FileName" value="example.smg"/>
    !--<![endif]-->
    <![if !IE]>
      <object id="_ComposerPlayerPlugin" type="application/x-composerplayerwebplugin" width="100%" height="100%">
      <param name="onload" value="ComposerWebPlayerLoaded" />
    ![endif]>

      <param name="_Version" value="262163"/>
      <param name="RenderGroundShadow" value="0"/>
      <param name="RenderMode" value="0"/>
      <param name="CameraPlayMode" value="1"/>
      <param name="AntiAliasingOnIdle" value="1"/>
      <param name="GroundGrid" value="1"/>
      <param name="AutoPlay" value="0"/>
      <param name="ShowViewBar" value="0"/>
      <param name="ShowDiapoBar" value="0"/>
      <param name="ShowMarkerBar" value="0"/>
      <param name="ShowStandardToolBar" value="0"/>
      <param name="ShowTimeLineBar" value="0"/>
      <param name="ShowMain3DToolBar" value="0"/>
      <param name="ShowCollabToolBar" value="0"/>
      <param name="ShowStatusBar" value="0"/>
      <param name="UseGUID" value="1"/>
    </object>

    where:

    • id is the name that identifies, the Composer Player ActiveX control for Internet Explorer and Composer Player Plugin for Firefox in the HTML file. The underscore (_) is used because id cannot start with a number.
    • classid is a unique identifier used by Windows to identify the Composer ActiveX control. This identifier typically does not change.
    • codebase is the path to the ComposerPlayerActiveX.cab file, which contains the Composer Player ActiveX (.ocx) file. The .cab file is necessary to publish your code one the Web. The version number is listed as FileVersion in the ComposerPlayerActiveX.inf file, which is in the .cab file. The .cab file is located in: <Composer_install_dir>\bin
    • param tags define properties such as the play mode, the render mode, and what toolbars to display. For details, see ActiveX Properties.

  3. Display the highlighted actor name in an HTML form:

    1. Create the form in which to write the text:

      <form action="" method="post" enctype="text/plain" name="highlight_form">
        <input type="text" name="highlight_text" value="none">
      </form>

      The important parts of this code are the form name (highlight_form) and the text name (highlight_text).

    2. Create two JavaScript functions that write the highlighted actor name to the form. The first function calls the myObject's (value assigned to myObject depends on the browser whether Internet Explorer or Firefox) HighlightedObject property and writes the actor name it returns in the form. The second function displays "none" if no actor is highlighted.

      <script type="text/javascript">
        function update_highlight_text() {
          var highlightstr;
          highlightstr=myObject.HighlightedObject;
          document.highlight_form.highlight_text.value=highlightstr;
        }
        function reset_highlight_text() {
          document.highlight_form.highlight_text.value="none";
        }
      </script>
    3. Call these two functions when GetHighlight and LooseHighlight events are notified: 
      <script type="text/javascript">
        function addGetHighlight() {
          addEvent(myObject, 'GetHighlight', function () {
            update_highlight_text();
          });
        }

        function addLooseHighlight() {
          addEvent(myObject, 'LooseHighlight', function ()
            reset_highlight_text();
          });
        }
      </script>
    4. Register these events in the onload of <body> tag. 
      <body onload="addGetHighlight(); addLooseHighlight()">
  4. Create two JavaScript functions that change the materials of the selected actors:
    1. Create two hypertext links that call the JavaScript functions: 
      <br>
      <A href="javascript:change_color_Glass()">Glass</A>
      <br>
      <A href="javascript:change_color_RedMetal()">Red Metal</A>
    2. Create the JavaScript functions. 
      <script type="text/javascript"> 
      function change_color_Glass()
      {
        var selectionstr;
        selectionstr=myObject.Selection;
        myObject.SetPropertySet(selectionstr,'<CLitPropertySet><Actor.Env.Effect Value="5"/></CLitPropertySet>');
        myObject.RefreshScene(1);
      }

      function change_color_RedMetal()
      {
        var selectionstr;
        selectionstr=myObject.Selection;
        myObject.SetPropertySet(selectionstr,'<CLitPropertySet><Actor.Env.Effect Value="2"/></CLitPropertySet>');
        myObject.SetPropertySet(selectionstr,'<CLitPropertySet><Actor.Color R="255" G="0" B="0"/></CLitPropertySet>');
        myObject.RefreshScene(1);
      } 
      </script>

      These functions use the SetPropertySet() method, which is an Advanced function requiring a Composer Player Pro license. 

  5. Create links on selected actors:
    1. Create an HTML form in which the user specifies the link destination: 
      <form action="javascript:add_link();" method="post" enctype="text/plain" name="link_form">
        <i>Enter a destination web address in the following text box.</i>
        <input type="text" name="link_text" value="Enter a URL">
        <br>
        <input type="submit" name="link_ok" value="Create the Link" >
      </form>
    2. Create the JavaScript function that adds the link: 
      <script type="text/javascript"> 
      function add_link()
      {
        var selectionstr;
        var linkstr;
        selectionstr=myObject.Selection;
        linkstr=document.link_form.link_text.value;
        myObject.AddLink(selectionstr,linkstr,1);
        myObject.RefreshScene(1);
      } 
      </script>

      The AddLink() method is an Advanced function requiring a Composer Player Pro license.
