Command Line Interface


You can access Composer and Composer Sync features from the command line.

Important:

  • A Composer Enterprise Sync or Configuration with Integration license is required to run command line APIs.

    Executables are located in: <install_dir>\<version>\bin
  • Executables cannot handle multi-process. Therefore, you cannot launch two identical processes at the same time. For example, you cannot launch two ComposerConverter.exe processes simultaneously.

Composer Parameters
‑updatex Updates a Composer file from a new source file.

Parameters:
  • <fileInput>: Specifies the Composer file (.smg or .smgXml) to update.
  • <fileAssociate>: Specifies the file containing up-to-date geometry. To use the same CAD file used to generate the Composer file, specify an empty parameter "" (two double quotes). The path to the original file is stored in the Composer file.
  • <fileSettings.xml>: Uses these settings if specified, otherwise uses default settings. See an example.
Composer.exe -updatex <fileInput> <fileAssociate> [<fileSettings.xml>]

‑update Updates a Composer file from a new source file.

Important: The -update switch implements the older geometry-based update behavior. Use the -updatex switch for the newer structure-based update behavior.

Parameters:
  • <fileInput>: Specifies the Composer file (.smg or .xmlGeom) to update.
  • <fileAssociate>: Specifies the file containing up-to-date geometry.
  • <fileSettings.xml>: Uses these settings if specified, otherwise uses default settings. See an example.
Composer.exe -update <fileInput> <fileAssociate> [<fileSettings.xml>]

‑generateImage Creates vector or raster images, or both, from a Composer file.

Parameters:
  • <fileInput>: Specifies the .smg, .smgXml, or .smgProj file for which images are generated.
  • <fileSettings.xml>: Specifies settings for image generation. For unspecified settings, defaults are used. See an example settings file.
    • To specify the output formats, set Batch.ImageOutputFormat (see the list of formats). If not specified, no images are generated.
    • To specify a Composer view file (.smgView) containing the views for which images are generated, set Batch.IOUseSmgView and Batch.IOSmgViewFile. If not specified, an image is generated for each view contained in (for .smg) or referenced by (for .smgXml or .xmgProj) the input file.
    • To specify High Resolution Image (.smgHighResSet) or Technical Illustration (.smgVectoSet) workshop profiles, set Batch.IOProfileHighRes or Batch.IOProfileVecto.
Note: Specify files with absolute paths.
Composer.exe –generateImage <fileInput> <fileSettings.xml>
Example:
Composer.exe –generateImage "C:\Models\model1.smg" "C:\fileSettings.xml"

‑merge Places all objects in the specified files into a new output file.

Parameters:
  • <listFilesToMerge.xml>: Lists all files to merge. See an example.
  • <fileOutput>: Specifies the output file (.smg or .xmlGeom).
  • <fileSettings.xml>: Uses these settings if specified, otherwise uses default settings. See an example.
Composer.exe -merge <listFilesToMerge.xml> <fileOutput> [<fileSettings.xml>]

‑getIssuedFrom Generates a list of CAD files from which a Composer file is built.

Parameters:
  • <fileInput>: Specifies the Composer file (.smg or .xmlGeom).
  • <fileOutput>: Specifies the output file (XML format) to which the CAD references files are listed.
Composer.exe -getIssuedFrom <fileInput> <fileOutput>

-removeIssuedFrom Removes from a Composer file the objects from a CAD source file.

Parameters:
  • <fileInput>: Specifies the Composer file (.smg or .xmlGeom).
  • <fileIssuedFrom>: Specifies the CAD file whose objects are removed.
Composer.exe -removeIssuedFrom <fileInput> <fileIssuedFrom>

‑rightManager Modifies Right Manager features. For example, you can add or remove the ability to use cutting planes, to add annotations and measurements, or to save a file.

 Parameters:
  • <fileInput>: Specifies the Composer file (.smg or .xmlGeom) to which Right Manager features are assigned.
  • <fileSettings.xml>: Specifies the Right Manager features using the <Batch.OptionPro> setting. See an example. See the list of Right Manager features.
  • <fileOutput>: Specifies the resulting Composer file with the modified features. If not specified, the input file is overwritten.
Note: The OptionsPro registry key sets the default <batch.OptionPro> value:

HKEY_CURRENT_USER\Software\Dassault Systemes\Composer\Preferences\OptionsPro

The default value after installation is 0, meaning no features are enabled.
Composer.exe -rightManager <fileInput> <fileSettings.xml> [<fileOutput>]

‑clearanceChecking Runs clearance checking on a selection using a specified profile.

Parameters:

  • <fileInput>: Specifies the Composer file (.smg, .smgXml, or .smgProj).
  • <fileProfile>: Specifies the clearance checking profile.
  • <mode>: Specifies which actors participate in the test:
    • CheckSel: Checks only actors in <selection1>.
    • Sel1VSAll: Checks actors in <selection1> against all other actors.
    • Sel1VSSel2: Checks actors in <selection1> against the actors in <selection2>.
  • <selection1>: Specifies the first selection set.
  • <selection2>: Specifies the second selection set. Required when <mode> is Sel1VSSel2.
Note: Specify all files with absolute paths.

This command creates a new file with the same names as <fileInput> but with a .xml extension.
Composer.exe -clearanceChecking <fileInput> <fileProfile> <mode> <selection1> [<selection2>]
Example:
 Composer.exe –clearanceChecking "C:\Models\model1.smg" "C:\Models\profileModel1.smgClashStaticSet" Sel1VSAll "Selection 1"

 Note: This example creates a model1.xml output file.

Sync Parameters

Syntax

Description
Sync.exe [-batch] [<fileSettings>] [-verbose:no] Launches Sync.

Parameters:
  • <fileSettings>: Specifies the Sync batch file to load in the graphical interface at startup (when -batch is not specified) or to execute (when -batch is specified).
  • -batch: Executes the specified batch file without opening the graphical interface.
  • -verbose:no: Disables output messages. Use with -batch.
Return Values: Sync always returns "0" (success). To get return codes for file translations, call Converter  (ComposerConverter.exe) directly.
Sync.exe -batch c:\My_Folder\mybatch.seeb -verbose:no

Converter Parameters

Syntax

Description
Converter.exe <fileInput> <fileSettings.xml> Translates a file to another format. Called by Sync to perform file conversions.

Parameters:
  • <fileInput>: Specifies the file to convert.
  • <fileSettings.xml>: Specifies the formats to convert to. See an example. See the list of formats.
Return Values: See Converter Return Codes.

Note:
  • Call Sync (Sync.exe), not Converter (ComposerConverter.exe), except in cases where return codes are required.
  • To suppress message boxes during conversion, specify the following in your fileSettings.xml file: <Batch.VerboseMode Value="0"/>
ComposerConverter.exe c:\My_Folder\Name_Of_CAD_File.CATProduct Settings.xml

Sample listFilesToMerge.xml File

The Composer.exe -merge command requires an XML file that lists the files to merge. For example:

<ListFiles>

<File ComponentName="" CreateSubComponent="1">C:\Bureau\Part1.CATPart</File>
<File ComponentName="Sample" CreateSubComponent="0">D:\Models\batch\Part2.model</File>
<File>D:...</File>
...
</ListFiles>
